# Disclaimer

This repository contains utility data models, analytical templates, Power Query functions, and Tabular Model Definition Language (TMDL) definitions for Power BI.

Outputs, calculations, and compliance assessments generated from these models require independent professional review and validation before being relied upon for financial reporting, tax compliance, or statutory filings.

All sample data files in `samples/` are entirely fabricated using fictional entities and synthetic transaction amounts.

Sample ACNs are blank. Fund names and `DEMO-FUND-*` identifiers are synthetic labels. The parent entity's sample ABN passes the checksum and returned ‘ABN not found’ in ABN Lookup on 12 November 2026; that observation is dated and the value is not reserved. These sample identifiers establish no registration or fund-routing authority.
