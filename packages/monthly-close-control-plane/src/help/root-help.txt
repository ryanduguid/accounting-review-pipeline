usage: close-control [-h]
                     {review,workbench,view,queue,reconcile,drivers,compare,classify,schedule,demo,jet,duplicates,fixed-assets,mcp,payroll} ...

Create a review-first monthly close control pack from validated trial-balance
exports.

positional arguments:
  {review,workbench,view,queue,reconcile,drivers,compare,classify,schedule,demo,jet,duplicates,fixed-assets,mcp,payroll}
    review (workbench)  run integrity, variance, mapping, and optional
                        reconciliation controls (as `workbench`, with the
                        local close-review banner)
    view                display an existing review pack after verifying its
                        four files agree
    queue               filter explicitly supplied close packs after verifying
                        every pack
    reconcile           review clearing-account transactions and carry
                        outstanding items forward
    drivers             rank the transactions behind each period variance in a
                        verified pack
    compare             compare verified close packs without changing them
    classify            compare postings with supplied bill-purpose evidence
    schedule            review a canonical expense, migration, inter-entity or
                        prepayment and accrual schedule
    demo                write the fabricated example inputs and review them,
                        with no checkout needed
    jet                 test a general-ledger listing's journals for entries
                        worth review, with a Benford first-digit test
    duplicates          list possible duplicate bills and payments and missing
                        recurring bills in a supplier register
    fixed-assets        tie a fixed-asset register's cost and accumulated
                        depreciation to the trial balance
    mcp                 serve the read-only commands to an assistant over
                        stdio (Model Context Protocol)
    payroll             reperform PAYG withholding and super guarantee on a
                        payroll register's 2026-27 pay lines

options:
  -h, --help            show this help message and exit
