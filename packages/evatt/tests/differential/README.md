# Differential and performance evidence

The oracle is the unchanged Python component archived from the supplied checkout,
`efa253847e4ecdca5ae9b4abec045c0b16b6835c`. The compatibility interpreter on ll was
CPython 3.14.8 with Unicode 16.0.0; the compiler was Rust 1.99.0. All inputs are
fabricated. Neither the oracle nor these scripts are runtime dependencies.

`detectors.py` compares every translated pattern's matches and captures before
arbitration, including rejected candidates and name retry positions. It also
compares the email scanner, structured spans, number cursor, residual sweep,
redaction, findings, mapped-value captures, full folding and NFC. Seeds 1 and 2
each ran 4,022 cases (2,000 grammar cases, 2,000 email cases and 22 directed
cases), with zero differences. `--shrink` reduces a discrepancy by deletion.

`cli.py` compares exits, both byte streams and every non-git file's bytes, mode,
link count and symlink target, recreating each worktree at the same path. Seeds
1 and 2 each ran 521 cases, including 300 random cases, with zero differences.
`cli-regressions.json` retains minimal fabricated examples of diagnostic
discrepancies found during implementation. Newly created disclosure records and
version output are compared after substituting only the version.

`arguments.py` adds 1,000 grammar-generated argument cases per seed, including
widths down to five columns. Both seeds passed after correcting the distinction
between private parent-parser diagnostics and ordinary child-parser errors.
An additional real timeout comparison killed a fabricated hung git after
30 seconds in each implementation, with identical exit code and diagnostics.

The Rust regression corpus contains 6,171 reachable core calls captured from the
original passing suite. `unicode-16.json` adds 4,555 multi-character combining
and casing cases generated by CPython. Cargo tests read these checked-in results
without requiring Python. Windows-only filesystem cases still need Windows.

`performance-results.json` records 130 release measurements on ll, on
13 October 2026. The four original families retain their constructions at
1, 2, 4, 8 and 16 times size. Measured 16-times timing growth ranged from
14.78 to 19.09; actual name starts/retries and number cursor inspections grew
within the asserted linear bounds. Regex-internal counters are unavailable,
so label and atomic-joiner evidence combines timings with the source grammar
arguments. This is no global linearity claim: map size, arbitration and sorting
are outside these matcher bounds. Debug timing tests use one tenth the sizes
with the same four-times comparison; release tests retain the original sizes.

Run commands are in `../../CONTRIBUTING.md`. To repeat the measurements:

```bash
cargo build --locked --release --features probe
python3.14 tests/differential/performance.py --probe target/release/evatt-probe \
  --output /tmp/evatt-performance-results.json
cargo test --locked --release --all-features --test performance
```
